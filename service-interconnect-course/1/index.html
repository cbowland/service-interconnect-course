Red Hat Service Interconnect

Introduction

This course teaches you how to use Red Hat Service Interconnect (based on the open-source Skupper project) to securely connect application services across multiple Red Hat OpenShift clusters, Kubernetes environments, and Red Hat Enterprise Linux systems — without requiring VPNs, special firewall rules, or elevated network privileges.

Red Hat Service Interconnect creates a Layer 7 service network that enables application-level connectivity between distributed workloads. Traffic is encrypted with mutual TLS by default, and no changes to the underlying network infrastructure are required.

Duration: approximately 8 hours

Objectives

On completing this course, you should be able to:

  • Describe the architecture and key concepts of Red Hat Service Interconnect

  • Install and configure Service Interconnect on OpenShift Container Platform 4.20

  • Create service networks that span multiple clusters and environments

  • Expose and consume services across site boundaries

  • Connect non-Kubernetes workloads using RHEL service gateways

  • Configure mutual TLS and understand the security model

  • Monitor service networks using the Network Observer console

  • Implement multi-cloud, edge, and progressive migration patterns

Prerequisites

This course assumes that you have the following prior experience:

  • Red Hat Certified Specialist in OpenShift Administration (EX280) or equivalent experience administrating OpenShift Container Platform 4.x

  • Basic familiarity with Kubernetes concepts (pods, services, deployments, namespaces)

  • Basic Linux command-line skills (RHCSA-level or equivalent)

  • Access to at least two OpenShift 4.20 clusters (provided in the lab environment)
