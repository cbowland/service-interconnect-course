= Working with RHEL Gateways
:navtitle: Working with RHEL Gateways

== Chapter Overview

In previous chapters, you connected services across OpenShift clusters.
Many organizations also run workloads on bare-metal servers, virtual machines, or edge devices running Red Hat Enterprise Linux.
Service Interconnect can extend the application network to these non-Kubernetes environments, enabling seamless connectivity between containerized and traditional workloads.

This chapter covers how to create Service Interconnect sites on RHEL systems, link them to OpenShift clusters, and expose services in both directions.

== Objectives

After completing this chapter, you should be able to:

* Describe the local system site platforms supported by Service Interconnect (Podman, Docker, Linux)
* Install and configure Service Interconnect on a RHEL 9 system
* Create a local system site and link it to an OpenShift-based application network
* Expose services running on RHEL to OpenShift workloads
* Consume OpenShift-hosted services from a RHEL system
* Use site bundles to deploy pre-configured sites to remote hosts
* Manage local system site lifecycle with `skupper system` commands
